This PCB is meant to control a rocket for a friend. It features 4 pyro channels for ignition wires (2 top, 2 bottom), an STM32, altimeter, barometric, acceleration, gps, etc. everything a fancy PCB needs. Theoretically, this pcb should act as the board to act as a flight controller for the rocket.
